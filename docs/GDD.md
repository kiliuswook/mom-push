# 엄마, 밀어! — 기획 요약과 구현 매핑

원본: `Mom, Push! Game Concept Proposal v0.2` (2026.05.12, 9p)
이 문서는 원본을 대체하지 않는다. **문서의 각 조항이 코드 어디에 살아 있는지**를 적는다.

## 한 줄 컨셉

> 병원에서 깨어난 휠체어 킬러가 마을 곳곳에 숨어 있는 암살자들을 찾아내고,
> 타임루프를 반복하며 모든 킬러를 제거한 뒤 탈출 지점까지 도달해야 하는 병맛 물리 FPS.

## 1. 이동 / 사격 분리 (문서 8절)

문서의 상태표를 그대로 규칙으로 옮겼다. **핵심은 "속도"가 아니라 "직접 굴리는 입력"이 사격을 막는다는 것.**

| 상태 (`Enums.Drive`) | 이동 | 사격 | 분산각 |
|---|---|---|---|
| `STOPPED` 완전 정지 | — | ✅ 정밀 조준 | 0.25° (조준 시 최대 0.09°) |
| `SELF` 직접 조작 중 | 2.6 m/s | ❌ | — |
| `COAST` 관성 롤 | 자동 | ✅ | 1.9° |
| `PUSHED` 엄마가 미는 중 | 7.6 m/s | ✅ | 3.4° |
| `CARRIED` 들려서 계단 이동 | 1.15 m/s | ❌ | — |

> 도망치려면 굴려야 한다. 하지만 죽이려면 손을 떼거나, 굴러가는 타이밍을 쓰거나, 엄마에게 맡겨야 한다.

정지 사격에는 반동으로 뒤로 밀리는 힘(`RECOIL_PUSHBACK`)이 붙는다 — 문서 13절의 "반동과 충격".

## 2. 킬러 판별 (문서 12절)

킬러는 적이 아니라 **정체를 알아내야 하는 함정**이다. 그래서:

- 외형(`disguise`)과 정체(`killer_type`)를 완전히 분리했다.
- `KILLER_CATEGORIES` 는 카테고리마다 후보 슬롯을 여러 개 두고 시드로 한 명만 킬러로 만든다.
  **나머지 후보는 같은 위장을 쓴 진짜 민간인이다.** 청소부가 셋인데 킬러는 하나다.

정체를 아는 경로는 셋뿐이다.

1. **텔 관찰** — 킬러는 26m 안에서 주기적으로 플레이어를 힐끗 본다 (`_tick_tell`).
2. **리빌 목격** — 무기를 꺼내는 순간을 보면 죽지 않고도 배운다 (`_engage` → `GameState.learn`). 정공법.
3. **죽는다** — 가장 확실하지만 루프를 하나 태운다 (`WheelchairPlayer.die`).

한 번 안 킬러는 다음 루프부터 머리 위에 붉은 마름모가 붙는다 (`Npc._refresh_marker`). 학습의 보상.

### 킬러 7종

| 타입 | 위장 | 공격 | 단서 |
|---|---|---|---|
| 클리너 | 청소부 | 11m 권총 | 빗자루를 놓고 허리춤으로 손이 간다 |
| 러너 | 조깅하는 사람 | 근접, **뒤로 돌아 접근** | 코스를 벗어난다 |
| 드라이버 | 자동차 운전자 | 차량 돌진 | 도로 진입 시 시동 |
| 택시 킬러 | 택시 운전사 | 급정차 후 22m 사격 | 옆으로 붙어 선다 |
| 배달 킬러 | 피자 배달부 | 폭탄 상자 투척(포물선) | 상자를 어깨 위로 든다 |
| 스나이퍼 | 창가 주민 / 옥상 작업자 | 85m 저격 | **붉은 레이저가 1.7초 먼저 스친다** |
| 군중 킬러 | 평범한 시민 | 8m 안에서 무기 | 거리를 좁혀야만 반응한다 |

## 3. 수배 단계 (문서 7절)

> GTA 처럼 난장판을 치는 게임이 아니라, GTA 식 난장판을 벌이면 반드시 망하는 게임.

사다리는 **내려오지 않는다** (ALERT 만 22초 후 가라앉는다).

```
이상 없음 → [빗나간 총성/목격] 신고 접수
          → [민간인 사살]      경찰 출동   (9초마다 2명 증원)
          → [경찰 사살]        SWAT 출동   (9초마다 3명 증원)
          → [SWAT 사살]        헬기 출동   (격추 가능하지만…)
          → [헬기 격추]        전투기 → 6초 후 강제 Game Over
```

헬기는 "이길 수 있지만 이기면 안 되는" 선택지로 일부러 남겨뒀다.

## 4. 탈출 (문서 4절)

> 탈출 지점으로 달리는 게임이 아니라, 도착하기 전에 모든 위협을 제거하는 게임이다.

- 킬러 전원 제거 후 진입 → 2초 체류 → 엔딩.
- 한 명이라도 남은 채 진입 → **남은 킬러 전원이 반경 11m 원형으로 재배치되어 360도 총격** (`EscapeZone._spring_ambush`).

## 5. 코옵 / 엄마 (문서 9·10절)

| 액션 | 키 | 구현 |
|---|---|---|
| 고속 밀기 | Shift (1P) / U·RB (2P) | `Mom.State.GRIP` |
| 급정지 턴 | Ctrl (1P) / O·LB (2P) | `_braking()` |
| 휠체어 점프 | Space | `JUMP_VELOCITY` |
| 도로 턱 넘기 | 자동 (밀리는 중) | `_try_step_up()` — `test_move` 스윕 |
| 계단 오르기 | P / X버튼 | `StairLift` + `Mom.State.CARRY` |

(엄마는 항상 휠체어 뒤에 있으므로 1P 시야 안에 들어온다).

## 7. 비언어 온보딩

플레이테스트에서 "무엇을 해야 할지 전혀 모르겠다"가 나왔다. 원인은 규칙이 어려운 게 아니라
**규칙을 문장으로만 말하고 있었다**는 것이다. 9줄짜리 조작 안내는 아무도 읽지 않는다.
그래서 설명을 전부 그림·공간·연출로 옮겼다.

| 플레이어가 가진 의문 | 이전 (문장) | 지금 (비언어) |
|---|---|---|
| 지금 쏠 수 있나? | "직접 굴리는 중 — 사격 불가" | 조준선 위 기호: 바퀴 + 총에 금지 사선 (`ActionHint`) |
| 그럼 어떻게 쏘나? | — | 막힌 채 방아쇠를 당기면 `[Shift] + 미는 그림`이 깜빡인다 |
| 조작이 뭐가 있나? | 9줄 텍스트 | 좌하단 `[키캡] + [픽토그램]` 8줄 (`HintPanel`) |
| 어디로 가나? | "탈출 지점까지 가야 한다" | 바닥을 흐르는 화살표 + 46m 빛기둥 (`GuidePath`) |
| 아직 가면 안 되나? | "모든 킬러를 제거하지 않으면 포위된다" | **빛기둥 색** — 붉으면 킬러가 남았고, 초록이면 나가도 된다 |
| 총은 어떻게 쏘나? | — | 병원 안 연습 과녁 3개. 맞으면 넘어간다 (`TargetBoard`) |
| 저 사람이 킬러인가? | 주황색 단서 문장 | **붉은 느낌표 + 발밑 파문 + 0.45초 슬로우모션** |
| 계단은? | "[P] 엄마가 들어올린다" | 공중에 떠서 까딱이는 `P` 키캡 (`Build.key_prompt`) |

설계 원칙 셋:

1. **상태는 그 상태일 때 보여준다.** 사격 제약은 미리 읽는 게 아니라 막히는 순간 알아야 한다.
2. **실패했을 때만 대안을 띄운다.** 못 쏘는데 방아쇠를 당겼거나, 굴리는데 안 나아갈 때만
   `Shift + 밀기`가 깜빡인다. 항상 떠 있으면 잔소리가 된다.
3. **가장 중요한 순간에는 시간을 늦춘다.** 첫 정체 노출은 이 게임의 규칙 설명 그 자체다.
   놓치면 배울 기회가 사라지므로 한 판에 한 번 슬로우모션을 건다.

단서 문장(“상자를 어깨 위로 들면 폭탄이 날아온다”)은 없애지 않고 **Tab 코덱스와 루프 화면으로
옮겼다.** 실시간에는 방해지만, 죽고 나서 읽을 때는 정확히 그게 필요하다.

## 8. 조작감 튜닝

플레이테스트 피드백: "휠체어 회전이 답답하다", "엄마가 미는 게 뭐가 다른지 모르겠다".
`tests/playtest.tscn` 으로 계측해서 원인을 숫자로 확인하고 고쳤다.

| 지표 | 이전 | 이후 | 근거 |
|---|---:|---:|---|
| 제자리 180° 회전 | 1.83초 | **0.60초** | 실제 휠체어는 멈춰 있을 때 제자리에서 홱 돈다 |
| 시야 90° 전환 후 추종 | 0.87초 | **0.35초** | 마우스가 곧 조향이어야 한다 |
| 자력 관성 활주 | 5.3m | **1.5m** | 5m 를 미끄러지면 위치를 잡을 수 없다 |
| 밀기 관성 활주 | 46.4m | **5.9m** | 맵 1/3 을 미끄러지던 것을 통제 가능한 활주로 |
| 급정지 거리 | 1.7m | **1.0m** | |
| 밀기 중 시야각 | 74 (동일) | **88** | 속도가 3배인데 화면이 같으면 체감이 안 된다 |

### 회전: 속도에 반비례하는 회전 속도

고정 회전 속도(1.7 rad/s)가 문제였다. 멈춰 있을 때도 트럭처럼 돌았다.
이제 정지에서 5.2 rad/s, 최고 속도에서 1.6 rad/s 로 보간한다.
현실의 휠체어와 같고, "멈춰서 조준한다"는 규칙과도 맞아떨어진다.

추가로 **마우스가 곧 조향**이 되었다. 이전에는 전진 중일 때만 의자가 시야를 따라왔다.
단 **조준(우클릭) 중에는 따라오지 않는다** — 의자를 고정한 채 주변을 훑기 위해서다.
A/D 는 의자와 시야를 함께 돌린다. 따로 돌면 시야가 뒤에 남아 방향을 잃는다.

### 관성: 속도 비례 감속

고정 마찰(0.62 m/s²)이라 저속에서는 질질 끌리고 고속에서는 영원히 미끄러졌다.
`감속 = 1.3 + 속도 × 0.55` 로 바꾸니 느릴 때는 딱 서고 빠를 때만 시원하게 활주한다.

### 엄마 밀기: 수치가 아니라 몸으로

3배 빠르다는 사실만으로는 아무도 차이를 못 느꼈다. 화면이 그대로였기 때문이다. 여섯 겹으로 알린다.

1. **첫 밀침** — 손잡이를 잡는 순간 +2.4 m/s 순간 추진과 시야각 펀치
2. **시야각** — 속도에 비례해 74 → 88도
3. **발걸음 리듬** — 2.3 Hz 로 속도가 ±16% 출렁인다. 자력 추진의 매끈함과 가장 다른 점
4. **노면 진동** — 속도에 비례한 카메라 흔들림
5. **바퀴 회전** — 살을 박아둬서 회전이 눈에 보인다
6. **상태 기호** — 조준선 위 픽토그램이 [엄마 밀기 + 총]으로 바뀐다

## 원본과 의도적으로 다르게 한 것

문서에 없거나 문서와 다른 결정들. 되돌릴 때 근거가 필요하므로 남긴다.

1. **싱글 플레이에서도 엄마가 존재한다.**
   문서상 엄마는 2P 전용이지만, 싱글에서 엄마를 빼면 "이동 중 사격 불가" 제약이 순수한 불편으로만 남는다.
   싱글에서는 엄마가 AUTO 모드로 1P 입력을 공유해 밀어준다. 문서 17절의 "조작이 답답할 수 있음" 대응.
2. **엄마는 표적이 되지 않는다.**
   암살자들이 노리는 것은 휠체어에 앉은 킬러뿐이라는 설정. 덕분에 2P 는 죽음 관리 대신 돌파에만 집중한다.
3. **루프 시작 3초 유예** (`Balance.LOOP_GRACE_TIME`).
   문서는 "처음에는 억울하게 죽는다"를 의도하지만, 침대에서 눈뜨자마자 죽는 것은 억울한 죽음이 아니라
   조작 불능이다. 유예 동안 킬러는 절대 먼저 움직이지 않는다.
4. **탄창 6발 + 재장전.** 문서에 없다. "쏘기 전에 확실히 하라"를 압박으로 만들기 위해 넣었다.
5. **군중 킬러를 MVP 에 포함.** 문서 MVP 는 5종이지만 군중 킬러가 있어야 "아무나 쏘면 안 된다"가 성립한다.
6. **클리어하면 새 시드로 재시작.** 지식이 초기화되고 배치가 바뀐다. 재플레이 가치.
